# Budgeted website

The public website and documentation shell for [Budgeted](https://github.com/budgetedhq/budgeted), published at [budgetedhq.github.io](https://budgetedhq.github.io).

```bash
pnpm install
pnpm dev
pnpm check
pnpm build
```

Documentation pages are Markdown files under `src/content/docs`.
